# Préférence graphique : Warsh avec points orientaux

L'utilisateur précise que le pilote est correct mais souhaite un fa avec point au-dessus et un qaf avec deux points au-dessus. La nouvelle recherche doit viser cette convention graphique, et pas seulement une édition plus récente. La riwaya Warsh reste impérative.

## Source examinée

[Mushaf Warsh — مصحف ورش المشرقي, Furqaan Media](https://play.google.com/store/apps/details?hl=ar&id=com.fm.mushafwarshalmashriqi).

`app-example.png` est une capture promotionnelle de cette fiche, téléchargée pour comparaison visuelle seulement :
https://play-lh.googleusercontent.com/GS03P1bMBQkoF3RN2Ldr8gveWQRrzes9eY-nOcoYrEv3NlMd9MgX3DPCx8MsnhF_rRU=w1200

La page montre le début d'Al-Baqara avec les points orientaux recherchés. Cela établit l'existence d'une présentation adaptée, pas la disponibilité d'un paquet réutilisable avec coordonnées ni ses droits de redistribution. Ne pas intégrer cette capture au site.

## Autre piste, non qualifiée

[Centre de téléchargement de l'éditeur Alwa7y](https://www.alwa7y.com/downloads/) : son HTML référence `TayseerWarsh.pdf`, distinct de `TayseerWarshAsbhany.pdf`. Le PDF n'a pas été inspecté pendant cette recherche ; ni sa présentation ni sa compatibilité ne sont donc certifiées.

## Suite

Qualifier un couple pages/coordonnées avec cette convention, vérifier le tariq et le décompte, puis proposer une page de comparaison. Ne pas déplacer les points dans les SVG existants ni substituer un corpus Hafs. Les coordonnées actuelles sont liées au graphisme du pilote et ne doivent pas être appliquées telles quelles à une autre mise en page.
