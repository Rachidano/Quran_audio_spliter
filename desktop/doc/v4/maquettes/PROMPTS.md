## Direction commune

Use case: ui-mockup. Create one exceptionally polished, realistic high fidelity WINDOWS DESKTOP application screenshot, landscape 16:10, around 1600x1000. Arabic RTL interface for "صانع مقاطع القرآن", a local Warsh Quran audio annotation and video creation application for nontechnical Arabic speaking users. This is a coherent V4 design concept, not a website or marketing poster. Straight-on flat screenshot filling canvas, no laptop mockup, no perspective, no huge outer borders. Windows slim titlebar. Consistent design system: warm off-white #F5F6F3 background, white surfaces, dark ink #172D29, deep emerald #12664F primary, restrained pale sage, amber only for review, thin separators, 8px rounded corners, spacious 24px gaps, 15–18px legible modern Arabic typography. Tasteful functional icons, no decorative emoji, no ornate gold branding, no gradients, no glassmorphism. Fixed narrow RIGHT sidebar with app name and simple open-book outline icon, navigation from top "المكتبة", "استوديو التقطيع", "إعداد الفيديو", "فيديوهاتي", "مجموعاتي", bottom "الإعدادات". Show active nav with pale green background and emerald right indicator. Main content LEFT of sidebar. RTL content hierarchy but audio timelines, timecodes and URLs genuinely LTR with Latin digits. One dominant emerald primary action per screen, neutral secondary actions; danger controls hidden in ellipsis menus. All UI text in natural legible Arabic except filenames/timecodes/URLs/shortcuts. No English commentary. Modest small footer "تصور الواجهة • V4". VERY IMPORTANT: Never invent or draw any Quranic verse text, calligraphy or pseudo-Arabic scripture. Every Quran image area must be a carefully styled warm-white placeholder labeled "صورة الآية من المصدر الرسمي" or "صورة صفحة المصحف" with simple light gray horizontal placeholder rules and a tiny image icon, not fake scripture. No verse counts from Hafs: if Baqarah count used it is 285 in this edition. Default reciter exact "الشيخ صابر الحكم". Warsh fixed no riwaya dropdown and no awjuh options. Do not include cloud, logins, AI transcription, social posting or subscriptions. Create only the specific screen below, not a contact sheet.
